MY SPACE — نسخه‌ی اولیه‌ی یکپارچه

اجرا:
- برای تست ساده، index.html را در مرورگر باز کن.
- برای نصب PWA و کار آفلاین، فایل‌ها را روی یک میزبان HTTPS قرار بده و از Chrome گزینه‌ی Install app / Add to Home Screen را بزن.
- داده‌ها در localStorage همان مرورگر و همان دستگاه نگه‌داری می‌شوند.
- از بخش تنظیمات می‌توانی یک خروجی JSON از داده‌ها بگیری.

محدودیت‌های مهم:
- قفل ورود فعلاً نمایشی است و هر رمزی را می‌پذیرد؛ امنیت واقعی/رمزنگاری و قفل مستقل بخش‌ها هنوز پیاده نشده.
- برخی امکانات پیشرفته‌ی طراحی‌شده (ویرایشگر کامل والپیپر، پرونده‌ی کامل کتاب‌ها، نمودارهای مهارتی مستقل، آرشیو/سطل زباله‌ی زمان‌دار و بازیابی امن) هنوز نسخه‌ی کامل ندارند.
- این بسته APK نیست؛ یک نمونه‌ی وب/PWA قابل توسعه است.
